# Spec issues
status: informative

Disagreements found while extracting the spec from `docs/architecture.md` and
the Rust reference implementation. A row beginning with **RESOLVED** records
the decision and regression coverage. All issues identified in this extraction
are resolved in `1.0.0-draft.3`; future disagreements must be added as new rows
before the draft can claim complete traceability again.

| id | area | description | where found |
|---|---|---|---|

| SI-002 | JRN | **RESOLVED in 1.0.0-draft.3.** Production admission/dispatch/receipt/checkpoint now uses the engine's linear transaction helpers; the parallel daemon writer was removed. Missing-checkpoint and checkpoint-without-terminal prefixes become `outcomeUnknown`; no dispatch, continuation, checkpoint or success is synthesized. | `crates/arkforge-engine/src/recovery.rs`, `crates/arkforged/src/jobs.rs recover_job`, AF-CONF-CRASH-005..011 |
